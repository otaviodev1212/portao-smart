# 🚪 Portão Smart V.1

Interface web para um sistema de **controle inteligente de portão**.

Este projeto representa a primeira etapa do desenvolvimento de um sistema completo de automação, focando inicialmente na criação da interface visual (Front-end).

---

## 📌 Sobre o Projeto

O **Portão Smart** tem como objetivo criar uma solução moderna para controle de acesso de portões, permitindo futuramente a integração com:

- API Backend
- Banco de dados
- Aplicativo mobile
- Microcontrolador ESP32
- Automação residencial

Atualmente este repositório contém apenas a interface Front-end.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Responsividade para dispositivos móveis
